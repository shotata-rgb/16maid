# 16MAID性格診断 (16MAID Personality Project)

あなたの中に眠る「メイドの真髄（奉仕と献身のスタイル）」を解き明かす、本格性格タイプ診断ツールです。
本家MBTI（16Personalities）のような清潔感と格調高いUIデザインを保ちながら、日常や仕事における全30問の心理設問から精密にタイプを分析します。

**Author / Developer: shotata**

---

## 🌟 主な特徴とシステム設計

1. **全タイプが必ず「M · A · I · D」になるアクロニム体系**
   - 旧来の `S · A · P · F` や `M · L · I · D` といった混在アルファベット表記を完全撤廃。
   - どのような診断結果であっても、タイプコードおよび4文字の属性は **`M · A · I · D`** に統一されます。
   - 各タイプごとに固有の4単語「M・A・I・D」が定義されており、自分のMAIDがどの英単語で構成されているかが一目瞭然です。

2. **あなたを形作る「4つのMAIDコア」と連動パラメータバー**
   - 診断結果画面では、自分固有の4単語（英単語・日本語訳・解説）がグラフィカルな4連カードで大きく表示されます。
   - パラメータ分析バーもその4単語（M, A, I, D）のスコアと直接連動し、自身の特性度合いがパーセンテージで視覚化されます。

3. **絵文字の完全排除（エレガント＆クリーンデザイン）**
   - サイト全体から絵文字（🔒, ✨, ☕, 🎀, ★等）を一切排除。
   - すべて洗練されたベクターSVGアイコン、CSSバッジ、タイポグラフィ、アクセントカラーで上品に表現されています。

4. **日常・仕事に関する普遍的な30問の設問**
   - メイド要素（「ご主人様」「屋敷」等）や事前の評価軸ラベル（M vs S等）を完全に排除。
   - 設問テキストと7段階の丸型ボタン（MBTI風）のみが表示され、思考を妨げずに直感的に回答可能。

5. **診断完了後に解放される「16タイプ大図鑑」**
   - 初回訪問時は図鑑にロック（鍵SVG）がかかっており、診断を最後まで完了したユーザーだけが図鑑（全16タイプの詳細・相性・固有MAID単語・SVGキャラクター）を閲覧可能。

6. **開発者モード（F12）イースターエッグ**
   - DevToolsコンソールを開くと、shotataのシグネチャ入りアスキーアートとメイドからのメッセージが出力されます。
   - コンソールで `shotata()` または `maid()` を実行すると隠しメッセージを体験できます。

## 🎀 全16タイプの「M · A · I · D」定義一覧

サーバー設置後に単語や日本語訳・解説を微調整したい場合は、`index.html` 内の `MAID_DATABASE` の各タイプにある `maidWords` オブジェクトを編集するだけで簡単に変更できます。

## 🔧 メンテナンス方法（サーバー設置時）

`index.html` 内の `MAID_DATABASE` 配列に各タイプの設定が集約されています。
単語の変更や日本語の言い回しを調整したい場合は、該当タイプの `maidWords` を編集してください。

```javascript
maidWords: {
  m: { letter: 'M', word: 'Methodical', ja: '周到', desc: '盤石の布石を打つ緻密な計画力' },
  a: { letter: 'A', word: 'Analytical', ja: '分析', desc: '感情に惑わされない客観的合理性' },
  i: { letter: 'I', word: 'Insightful', ja: '洞察', desc: '未来の展開を予見する高い先見眼' },
  d: { letter: 'D', word: 'Disciplined', ja: '規律', desc: '秒単位の自己統御と厳格な自律' }
}
```
